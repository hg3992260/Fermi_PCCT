# Quantum Atlas · 设计说明

> 从凝聚态 → 能带 → 自旋 → 光谱 → 液态自旋 → Bloch 动力学 → 量子计算 → 量子电路，
> 全部以三维交互呈现。本文说明**为什么这样切分**、**背后统一的物理框架**、**界面如何组织**，
> 以及**原型里哪些是真算、哪些是模型**。

---

## 0 一句话

这不是八个物理功能的拼盘，而是**同一条重正化流的八个站点**：每上升一层，就积掉一部分自由度，
留下一个有效生成元；每一层都可以写成「一个希尔伯特空间 + 一个生成元 + 一组可观测量 + 一个三维载体」。
界面的任务，是让用户在四类不同的三维空间之间安全地移动，并且始终知道自己在哪。

---

## 1 先批判：这八个词并不并列

你列出的八个对象——凝聚态、能带、自旋、光谱/半导体响应、液态原子自旋波函数、Bloch 运动方程、
量子计算、量子电路——如果直接做成八个标签页，会有三个结构性毛病：

1. **它们不在同一个空间里。** 晶格在实空间，能带在倒空间，Bloch 球与 Q-sphere 在状态空间，
   ε(ω)、M(T)、S(q,ω) 在参数空间。"全都三维"如果不区分这四类空间，用户会迷失方向。
2. **它们不是同一个尺度上的东西。** 从 Å 到 mm 跨 7 个数量级，从 neV 到 10 eV 跨 10 个数量级；
   并列摆放会掩盖"谁由谁涌现"这一最关键的物理。
3. **它们之间没有共享的"状态"。** 在能带里选中的 k 点、在自旋里选中的原子、在电路里选中的门，
   本应是同一个物理对象在不同层的投影；八个孤立 demo 做不到这种联动。

因此本设计先重构问题，再谈界面。

## 2 理论框架

### 2.1 一个母方程

所有八层都是同一个结构的特例：

```
∂ₜρ = −i[H, ρ] + Σₖ γₖ ( Lₖ ρ Lₖ† − ½{Lₖ†Lₖ, ρ} )        （Lindblad）
⟨A⟩(t) = Tr[ρ(t) A]                                        （观测）
χ_AB(ω) = Kubo 公式                                         （线性响应）
```

三个极限分别对应三个功能区：

| 极限 | 条件 | 出现在 |
|---|---|---|
| 纯态幺正 | γ = 0，ρ = \|ψ⟩⟨ψ\| | 量子电路（L8）、Bloch 球（L6） |
| 热平衡 | ρ = e^{−βH}/Z，线性响应 | 能带（L2）、自旋（L3）、光谱（L4） |
| 耗散主导 | γ ≫ 相干项 | 液态自旋扩散（L5）、T₁/T₂ 弛豫（L6） |

界面上的"时间轴"就是这条方程的积分变量：能带层是 k（周期性），自旋层是 t（进动/畴壁），
光谱层是 ω（傅里叶共轭），电路层是门的序号（分段常数 H）。

### 2.2 三条不变式

**不变式 1：谱定理。** 一切可视化的对象，要么是某个自伴算符的谱（本征值 + 本征矢），
要么是谱的几何载体。
- E(k)、ω(q)、S(q,ω)、ε(ω) 都是谱数据；
- 布里渊区、Bloch 球、Q-sphere 都是"谱的载体/基本域"。
> 这条不变式决定了渲染语法：**折线画结构，点画实体，三角面画谱曲面。**

**不变式 2：涨落–耗散。** 一切"响应"都是同一个关联函数的解析延拓。因此
ε(ω)（介电）、χ(ω)（磁化率）、S(q,ω)（液体）、以及 T₁/T₂（弛豫）在数学上是同一类量。
> 这条不变式决定了 L4 与 L5 可以共用同一套"曲面 + 投影"的视觉语法，也决定了
> 一个参数（例如温度或展宽）应当同时影响多个层。

**不变式 3：粗粒化。** 每一层都是上一层"积掉自由度"后的有效生成元：

| 从 → 到 | 积掉什么 | 得到什么 | 数学 |
|---|---|---|---|
| 晶格 → 能带 | 核坐标（绝热近似） | H(k) | 布洛赫定理 |
| 能带 → 局域自旋 | 巡游电子 | J_ij（超交换/RKKY） | Schrieffer–Wolff；RKKY ∝ cos(2k_F r)/r³ |
| 局域自旋 → 磁振子 | 量子涨落 | ω(q)（Goldstone 模） | 线性自旋波 |
| 局域自旋 → 宏观磁化 | 快变量 | M(r,t) | Landau–Lifshitz–Gilbert / Bloch 方程 |
| 周期体系 → 液态 | 平移对称 | g(r)、S(q,ω) | 关联函数；费米液体理论 |
| 二能级 → qubit | 连续自由度 | 门序列 | 分段常数 H，U = e^{−iHτ} |

### 2.3 八层站点

| 层 | 自由度 | 生成元 | 三维载体 | 涌现/可测量 | 原型数值方法 |
|---|---|---|---|---|---|
| **L1 凝聚态** | 核 + 价电子 | H = T + V + e²/r | 实空间晶胞；倒空间 BZ | 晶格常数、配位、BZ 形状 | 结构定义 + 倒格矢 + Wigner–Seitz 裁剪 |
| **L2 能带** | Bloch 态 \|nk⟩ | H(k) = e^{−ikr} H e^{ikr} | (k, E) 曲面 / 费米面 | 带隙、有效质量、费米面 | 经验赝势（EPM）+ Jacobi 对角化 |
| **L3 自旋** | 局域矩 S_i | ΣJ_ij S_i·S_j + DΣ(S_i^z)² | 箭头场 + 磁振子谱 | 磁序、ω(q)、M(T) | 经典基态 + 线性自旋波 |
| **L4 光谱** | 极化 P(q,ω) | χ = Kubo | (ω, ε₁, ε₂) 曲线 | ε∞、n、κ、α、E_g(T) | JDOS + 动量矩阵元 + Kramers–Kronig |
| **L5 液态** | 无序自旋旋量 | 费米液体 / 无序 Heisenberg | 构型 + g(r) + S(q,ω) | 配位壳、自旋扩散 D | RSA 构型 → g(r) → S(q) → 扩散型 S(q,ω) |
| **L6 Bloch** | 二能级 / M(t) | Bloch 方程 | Bloch 球 + 轨迹 | T₁、T₂、拉比频率、失谐 | RK4 积分 |
| **L7 量子态** | n-qubit 纯态 | 无（瞬时态） | Q-sphere + ρ | 纠缠度、熵、参与基态数 | 复数态矢 + Q-sphere 映射 |
| **L8 电路** | 门序列 | 分段 H(t) | 演化塔 + 电路图 | 概率分布、最概然态 | 复矩阵乘法 |

### 2.4 四条关键的跨层公式

**(a) 晶格 → 能带（本原型的实际算法）**

```
H_GG'(k) = (ħ²/2m)|k+G|² δ_GG' + V(|ΔG|²) · Φ(ΔG)
```

其中 Φ 是实数结构因子。取**反演中心为原点**时 Φ 为实数，H 实对称，可用 Jacobi 一次求出
全部本征值与矢量——这正是"能带"这一层在数值上的最小实现。

**(b) 能带 → 光谱**

```
ε₂(ω) ∝ (1/ω²) Σ_{v,c} |p_cv|² δ(E_c − E_v − ω),    p_cv = Σ_G c_c*(G)(k+G)c_v(G)
ε₁(ω) = 1 + (2/π) P∫ ω' ε₂(ω')/(ω'² − ω²) dω'
```

这不是"画一条漂亮的曲线"：ε₂ 由真实带间跃迁求和，ε₁ 由 Kramers–Kronig 变换得到，
所以带隙、临界点、以及"带隙变大时吸收边蓝移"会**自动**出现，而不是手工调参。

**(c) 能带 → 局域自旋 → 磁振子**

超交换 `J ≈ 4t²/U`（Schrieffer–Wolff 二阶微扰）给出局域矩之间的耦合；
方格子线性自旋波：

```
FM:  ω(q) = 2JSz(1 − γ_q) + Δ,      γ_q = (cos q_x + cos q_y)/2
AF:  ω(q) = 2JSz √(1 − γ_q²) + Δ
```

Δ = 2DS 是各向异性隙。界面上拖动 J、D，磁振子带宽与隙同步变化——这就是"同一枚箭头在
三个尺度上是三种东西"的可操作版本。

**(d) 二能级 → Bloch 球 → 门**

```
dM/dt = γ M × B − (M_x/T₂, M_y/T₂, (M_z−M₀)/T₁)
```

Bloch 球上的一点就是密度矩阵 ρ = (1 + M·σ)/2；一个 qubit 的门就是绕某轴旋转这个矢量。
所以 L6 与 L7 用的是同一套状态空间几何，只是维数不同（CP¹ vs CP^{2ⁿ−1}）。

### 2.5 为什么"必须"三维：四类空间

"全部用三维"不是炫技，而是因为每一层的数据本来就有三个天然维度，而且**类型不同**。
界面在每个视口左上角标注当前空间类型（这是本设计的一个硬规则）：

| 空间 | 维度含义 | 载体 | 出现在 |
|---|---|---|---|
| **实空间 R³** | 位置 | 晶胞、箭头场、原子构型 | L1、L3、L5 |
| **倒空间 (R³)*** | 波矢 | BZ 多面体、(k, E) 曲面、费米面 | L2 |
| **状态空间** | 振幅/相位 | Bloch 球（CP¹）、Q-sphere | L6、L7 |
| **参数空间** | 两个响应分量 + 频率 | (ω, ε₁, ε₂)、M–H | L4、L3 宏观 |

四类空间各有其"合法性来源"：
- 倒空间的合法性来自**平移群的不可约表示**——布里渊区就是倒格子的 Wigner–Seitz 胞；
- 状态空间的合法性来自**对称群的轨道**——Bloch 球是 SU(2) 的齐性空间 SU(2)/U(1)；
- Q-sphere 是 2ⁿ 维希尔伯特空间的**半径–相位嵌入**（纬度 = 汉明重量，经度 = 复相位）；
- 参数空间的合法性来自**响应函数的解析结构**（Kramers–Kronig 把 ε₁ 与 ε₂ 绑在一起）。

### 2.6 "布拉赫运动函数"的三种读法

你写的"布拉赫"应当指 **Bloch**。它在物理里有三个互不等价的含义，本设计把三者都实现，
并在界面上明确区分（L6 的三个视角）：

1. **Bloch 定理**：周期性势场中的波函数 ψ_nk = e^{ikx} u_nk。→ 一维链 + 波函数 + 周期包络。
2. **Bloch 球**：二能级纯态的空间 CP¹。→ 球 + 态矢量。
3. **Bloch 方程**：磁化/布居数的一阶运动方程，含 T₁、T₂ 与驱动。→ 球内轨迹 + 弛豫曲线。

三者的共同点是"**把连续问题约化到有限维**"：定理把连续空间折成能带指标，球把二维复矢量折成一个点，
方程把这个点的演化写成一阶流。这个共同点就是把它们放在同一层（L6）的理由。

## 3 界面设计

### 3.1 布局：五区一轴

```
┌──────────────────────────────────────────────────────────────────────┐
│ ① 标题栏：应用标识 · 体系选择 · 层徽标 · 主题/帮助/导出              │
├──────────┬────────────────────────────────────────────┬──────────────┤
│ ② 尺度   │ ③ 三维视口                                  │ ④ 检查器     │
│   导航   │   · 空间徽标（实/倒/态/参）                 │   · 控制      │
│  L0…L8   │   · 图例 · 相机预设 · FPS/图元数            │   · 读数      │
│          │   · 标签层（HTML 投影）                     │   · 本层物理  │
│  尺度条  ├────────────────────────────────────────────┤              │
│          │ ⑤ 时间轴：播放 · 滑块 · 当前值              │              │
│          ├────────────────────────────────────────────┤              │
│          │ ⑥ 状态栏：提示 · 联动状态                    │              │
└──────────┴────────────────────────────────────────────┴──────────────┘
```

- **① 标题栏**：无边框窗口 + `<x-titlebar>`（Electron 下可拖动）；体系下拉切换材料，
  层徽标实时显示"L2 · 能带"。
- **② 尺度导航**：九项（L0 全景 + L1–L8）。底部有一条"尺度条"，随当前层填充，
  用一条渐变色暗示 Å→mm 的跨度，避免用户忘记自己在哪个尺度。
- **③ 视口**：唯一的 3D 区域。左上角是**空间徽标**（颜色随空间类型变化），
  右上角是帧率与图元数（性能可视），右下角是相机预设（等轴/俯视/正视/重置）。
  电路层时视口变为"左电路 / 右演化塔"的分屏。
- **④ 检查器**：三段式。「控制」由场景声明式生成（滑块/开关/分段/下拉），
  「读数」是等宽字体的数值表（实时更新），「本层物理」是一段 2–4 句的解释，
  告诉用户"这层在算什么、为什么这样画"。
- **⑤ 时间轴**：每层语义不同——路径位置（L2）、时间（L3/L5/L6）、光子能量（L4）、门序号（L8）。
  无时间概念的层（L0/L1/L7）显示"静态视图"并禁用滑块。
- **⑥ 状态栏**：左侧是操作提示，右侧是**联动状态**（例如"联动：ħω → 能带层跃迁箭头"）。

### 3.2 交互模型：六条规则

1. **左键拖动 = 轨道旋转；滚轮 = 缩放；右键/Shift 拖动 = 平移。**
   不做"第一人称飞行"——科学可视化需要稳定的参照系。
2. **单击 = 拾取**（屏幕空间投影距离，容差 10–26 px），拾取后：高亮 + 右侧读数更新 + 状态栏说明。
   点击空白 = 取消选中。
3. **跨层联动只走"显式通道"**：L4 的光子能量会在 L2 画一条跃迁箭头；L0 的平台点击 = 进入该层。
   不搞隐式魔法，避免用户不知道为什么画面变了。
4. **时间轴可播放**（Space），播放时每帧推进 0.35 个归一化单位；到端点回环。
5. **相机有"记忆"**：每层有独立的默认机位（距离/俯仰/方位/目标点），切换层时恢复；
   R 键回到该层默认机位。
6. **深链接**：`?scene=bands&material=Ge` 可直接进入某层某材料；`?snap=1` 是给无头截图用的
   快照模式（把 WebGL 缓冲转成 `<img>`，因为部分 headless 合成器不写 canvas 层）。

### 3.3 视觉语法

**三种图元 = 三种语义**（这是整个设计最硬的一条约束）：

| 图元 | 语义 | 用途 |
|---|---|---|
| **折线** | 结构 / 边界 | 晶胞棱、BZ 棱、能带曲线、色散、轨迹 |
| **点** | 实体 / 离散态 | 原子、k 点、Q-sphere 节点、概率幅节点 |
| **三角面** | 谱曲面 / 体 | E(kx,ky)、S(q,ω)、柱状、半透明参考面 |

**色彩编码**（三层含义，不混用）：

- **空间**：实空间=琥珀，倒空间=冰蓝，状态空间=紫，参数空间=青绿；
- **量**：能量=冷→热渐变（蓝→青→黄→红），相位=色相环（蓝→品红），自旋=上青下品红；
- **状态**：选中=白点+描边，当前=青绿描边，禁用=降饱和。

**排版**：UI 用 Inter/思源黑，数值一律等宽（拖动滑块时字宽不跳）。字号阶梯 10 / 11.5 / 13.5。
- 暗色为默认（科学可视化对暗场更友好），提供明暗切换（跟随 Xel 主题）。

### 3.4 九个场景

下面每层给出：**目的 / 三维内容 / 可调参数 / 读数 / 联动**。

#### L0 全景 · 尺度塔
- **目的**：一张"地图"。让用户一眼看到八层不是并列功能，而是一条向上的流。
- **三维内容**：螺旋阶梯，八个平台各带一个字形（立方体 / 上升曲线 / 箭头环 / 谱峰 / 散点 /
  球+矢量 / 球+节点 / 电路），平台间有向上的"重正化"箭头，中心是能量轴。
- **交互**：点击平台进入该层；拖动旋转整座塔。
- **读数**：站点数、尺度跨度、能标跨度、贯穿不变式。

#### L1 凝聚态 · 晶格
- **目的**：把"对称性"变成可看的几何。
- **三维内容**：上半部是晶胞（棱 + 基矢箭头 + 原子 + 最近邻键），下半部是**第一布里渊区**
  （倒格子的 Wigner–Seitz 胞，用半空间裁剪求出），中间一个 ℱ 箭头表示傅里叶变换。
- **参数**：超胞 1/2/3、显示 BZ、显示键、显示晶胞棱。
- **读数**：晶格常数、原胞体积、原子数、|b₁|、结构类型。
- **联动**：点原子 → 状态栏显示物种与坐标；材料切换 → BZ 形状改变（fcc 截角八面体 / bcc 菱形十二面体）。

#### L2 能带 · E(k)
- **目的**：同时展示"能带是布里渊区上的函数"和"能带图是它沿路径的切片"。
- **三维内容**（三种视图，分段切换）：
  1. **带状**：左侧是高对称路径展开的能带图（占据带蓝、空带紫、选中带琥珀、当前 k 白色切片 +
     竖排点阵）；右侧是把同一路径放回 BZ 的真实几何（琥珀折线）。
  2. **曲面**：E_n(kx, ky, kz=0) 的三角网格曲面。
  3. **费米面**：E = E_F 的 k 空间点云（金属/狄拉克体系）。
- **参数**：视图、带指标、显示带数、BZ 开关。
- **读数**：带隙（模型值 + 实验值对照）、直接带隙、E_n(k)、平面波数、耗时。
- **联动**：L4 选中光子能量后，在 L2 的当前 k 画一条 ħω 跃迁箭头。

#### L3 自旋 · 原子→宏观
- **目的**：同一枚箭头在三个尺度上的三种身份。
- **三维内容**（三档）：
  - **单原子**：进动锥 + 态矢量 + 右侧能级标尺（E(m) = Dm² − gμ_B Bm 的劈裂）。
  - **点阵**：9×9 经典矩箭头场（颜色 = M_z），右侧是磁振子色散 ω(q)（Γ→X→M→Γ）。
  - **宏观**：M(T) 曲线（Brillouin 自洽解）、磁滞回线 M(H)、以及底部的畴壁纹理。
- **参数**：尺度、磁序（FM/AF/条纹/螺旋/斯格明子）、J、D、B、T。
- **读数**：随档位切换（能级劈裂 / 磁振子带宽与波速 / 约化磁化与相）。

#### L4 光谱 · 半导体响应
- **目的**：把"响应"画成一个三维曲线的形状，而不是二维折线。
- **三维内容**：主曲线 (ω, ε₁, ε₂)；ε₁=0 平面上的 ε₂ 投影；ε₂=0 平面上的 ε₁ 投影；
  后方平面上的吸收系数 α(ω)；带隙处的绿色虚线。
- **参数**：温度（Varshni 移动带边）、展宽 Γ、显示 ε₁/α。
- **读数**：ε₁/ε₂、n、κ、α、E_g(T)、ε∞。
- **联动**：点击曲线 → 设定 ħω → L2 出现对应的跃迁箭头。

#### L5 液态 · 自旋波函数
- **目的**：在没有晶格的地方，"自旋波函数"还剩什么。
- **三维内容**：150 个 ³He 原子的无序构型，每个原子带一个**旋量箭头**（长度 = 幅度，
  色相 = 相位）；右侧是实测 g(r)；后方悬浮的是 S(q,ω) 曲面（S(q) × 扩散型 Lorentzian）。
- **参数**：原子数、构型种子（重建无序实现）、自旋扩散 D、显示 S(q,ω)/g(r)。
- **读数**：数密度、第一配位壳、g(r) 峰值、S(q) 主峰、D。
- **物理注释**：k 不再是好量子数，但关联函数仍是；³He 是费米液体，低能激发是准粒子。

#### L6 Bloch · 运动方程
- **目的**：把"Bloch"的三个含义显式分开（见 §2.6）。
- **三维内容**：
  - **Bloch 球**：球 + 主轴 + 态矢量 + 轨迹（颜色随 t 渐变），随时间衰减并回落到 +z。
  - **Bloch 定理**：一维离子链 + Re ψ(x) + |u|² 周期包络 + 能带折叠示意。
  - **弛豫曲线**：M_z(t) 与 √(M_x²+M_y²) 两条曲线 + 当前时刻切片。
- **参数**：视角、B₀、B₁、ω、T₁、T₂。
- **读数**：|M|、M_z、横向分量、Larmor ω₀、失谐 Δ。

#### L7 量子态 · Q-sphere
- **目的**：让 2ⁿ 维复矢量"有形状"。
- **三维内容**：Q-sphere（球骨架 + 每个汉明重量一个纬度环 + 每个基态一个节点：
  半径 = 振幅模，经度 = 相位，大小 = 概率）；可选密度矩阵柱状（右侧，蓝色实部/品红虚部）。
- **参数**：比特数 n（1–4）、预设态（|0…0⟩、Bell、GHZ、W、均匀叠加、随机）、ρ 柱状开关。
- **读数**：希尔伯特维数、参与基态数、香农熵、归一化、concurrence（2 比特）。

#### L8 量子电路
- **目的**：把"门序列 = 分段常数哈密顿量"变成可见的演化。
- **三维内容**：**演化塔**——x 轴是基矢，z 轴是时间步，y 轴是振幅，颜色是相位；
  当前步高亮。左侧分屏是电路编辑器（门调色板 + 网格：左键放置/替换、右键删除，
  双比特门自动把下一根线当目标）。
- **参数**：比特数、示例电路（Bell / GHZ / 旋转+测量 / 清空）。
- **读数**：门数、当前步、最概然态及其概率、参与基态数。
- **联动**：拖动底部滑块 = 逐门步进；演化塔当前行与电路当前列同步高亮。

### 3.5 状态模型与场景契约

所有场景共享一个扁平状态对象 `S`（约 40 个键），场景只需实现四个成员：

```js
{
  id, name, space, spaceNote, note,     // 元信息（徽标、说明）
  time: { label, min, max, step, get, set, fmt },   // 时间轴语义
  params: [ { key, label, type, min, max, step, unit, hint } ],
  build(v, S),                          // 声明式绘制（每帧调用）
  readout(S) -> [{k, v, cls}]            // 读数表
}
```

这样做的收益：
- **新增一层**只需加一个文件 + 一行 import，外壳完全不用改；
- **参数面板自动生成**，不会出现"某层的滑块忘了接"这类 bug；
- **读数与三维同源**：两边都从 `S` 读，不会出现"画面改了数字没改"。

### 3.6 性能与缓存

- **渲染**：按需渲染（`v.request()` 合并同一帧的多次请求），只有动画/播放时才连续出帧。
- **缓存**：能带结构按 `(材料, 基组大小, 网格)` 缓存；介电函数按 `(材料, T, Γ)` 缓存；
  曲面/费米面按 `(材料, 带指标)` 缓存。切换材料才重算（EPM 一次约 350 ms）。
- **规模控制**：带图 46 个平面波 × 118 个 k 点；E(kx,ky) 曲面 26×26；JDOS 6³×26；
  费米面 15³ 采样。全部在几百毫秒量级，交互不卡。
- **降级**：曲面/费米面计算时显示 throbber；出错时把异常写到状态栏（不静默失败）。

### 3.9 视觉系统 v2（实现版）

原型第一版的界面只是"能用"；高质量版本把**令牌、栅格、动效、暗场策略**都固定下来。

**主题分两层**：`theme/atlas-dark.css` 与 `theme/atlas-light.css` 各自 `@import` Xel 的
`fluent-dark.css` / `fluent.css`，然后只覆盖两类东西——**语义令牌**（背景/前景/边框/文字/强调色）
与**几何**（6/8/10px 三档圆角、滑块与开关的尺寸）。这样 Xel 组件的内部结构完全不用碰，
升级 Xel 也不会崩。应用自己的面板颜色走另一组变量（`--bg-1/2/3`、`--line`、`--ink`），
两套令牌在 `body.light` 中同时切换。

**视口恒为暗场**（一条明确的取舍）：3D 图元大量使用发光色、半透明面与相位色，
在浅底上会失去对比度。所以浅色主题只把 chrome 变亮，画布保持暗场；视口内的浮层
（空间徽标、图例、相机导轨、忙碌提示）用统一的"深色玻璃"变量 `--glass-*`，
两种主题下外观一致。这样避免了两套 3D 配色，也避免了"浅色主题下能带看不清"。

**布局**（46 + 1fr + 56 + 26）：

```
标题栏 46px  ┌ 品牌 ─ 菜单(文件/视图/图层/帮助) ────── 体系 ▾ · 图层徽标 · 主题/帮助 ┐
栅格          │ 左 236px            │ 中 1fr                      │ 右 332px          │
              │ 分组导航 + 尺度条   │ 视口（空间徽标 / 图例 / 相机）│ 图层头 + 控制/读数 │
              ├─────────────────────┴─────────────────────────────┴───────────────────┤
传送带 56px   │ 播放 · 步进 · 滑块 · 数值+单位                                      │
状态栏 26px   │ 提示 · 空间/尺度 · 联动状态                                          │
```

**细节规则**（这些是"看起来专业"的真正来源）：

| 项 | 规则 |
|---|---|
| 间距 | 8px 节奏；面板内边距 12/14/16；块间距 14 |
| 发丝线 | 1px `--line`（比 Xel 的 `--border-color` 更淡），用于内部分层 |
| 字号 | 9.5（eyebrow/角标）/ 10.5（辅助）/ 11.5（正文）/ 13–15（标题） |
| 数字 | 一律 `font-variant-numeric: tabular-nums`，拖动滑块时字宽不跳 |
| 强调色 | 只出现在"当前状态"：选中图层条、当前视图分段、播放中、被拾取对象 |
| 动效 | 120–200ms；只有 hover/选中/相机，不做装饰性动画 |
| 空态 | "本层无参数：直接点击三维对象"；静态层的时间轴显示"静态视图" |
| 忙碌 | 重算前先让出一帧，显示胶囊形进度条，避免"点了没反应" |

**导航**用分组标题（全景与结构 / 电子结构 / 自旋与响应 / 动力学与量子）而不是九个平铺项，
让"尺度在上升"这件事在左栏就成立；每项右侧是图层编号（等宽小字），与快捷键 1–9 对应。

**菜单栏**给了真正的桌面语义：文件（导出/复制链接/退出）、视图（机位/主题/图例）、
图层（1–9 快速跳转）、帮助（理论框架/快捷键/关于）。快捷键用 `x-shortcut` 显示，
与键盘处理一一对应。

**3D 侧的三处打磨**：标签做**优先级去重叠**（tag 优先占位，dim 遇冲突直接丢弃），
被拾取对象画一圈**朝向相机的选中环**，地面网格做**径向淡出**（注意力收回中心）。

**第二批增补（"可读性"而非"好看"）**：

| 增补 | 做法 | 为什么值得 |
|---|---|---|
| **迷你坐标轴** | 视口右下 58px 的 SVG，把世界三轴按相机基矢投影；朝向相机的轴更亮，两点排序保证遮挡次序 | 旋转后立刻知道"我现在的视线从哪来" |
| **读数趋势条** | 6 点试探找出"随扫描参数变化最明显"的那个读数，再做 16 点采样画成 26px 折线，并标出当前位置 | 把"滑块拖过去会发生什么"提前告诉用户，而不是让他一个个试 |
| **参数预设** | 「恢复默认 / 保存为默认 / 复制 JSON」，存 localStorage，进入图层时自动恢复 | 实验性工具必须能"回到已知状态"，也必须能把手上的参数发给别人 |

趋势条带**预算保护**：试探如果超过 120ms（例如液态层要重建无序构型），该层自动放弃趋势，
避免为了一个装饰性的小图卡住交互。所有候选量都不随扫描变化时（例如"门数"）也不显示——
宁可空着，也不给一条假的水平线。

### 3.11 科学可读性的两处补齐

**能带层：能量轴 + 带隙标注。** 之前只有高对称点标签，读数要靠右侧表格，图上无法直接量。
现在左侧有一条独立能量轴：`E − E_VBM (eV)`（金属为 `E − E_F`），每 2 eV 一个刻度并拉出轻网格线，
零点加粗；同时在导带底所在 k 处画一个绿色的双箭头与 `E_g = 1.135 eV` 标注——
**带隙从"读数"变成"图上可量"**。能量压缩比在 ±7.6 eV 处硬截断，保证 ±6 eV 的刻度落在真实位置。

**光谱层：从"一团投影"改成"一个三维坐标系"。**
原来的三条投影都从同一个角落出发、互相压在一起。现在改成：

- **地面** = (ω, ε₂)，**后墙** = (ω, ε₁)，主曲线悬在两者之间——三者的关系一眼可读；
- ω 轴每 1 eV 一个刻度（每 2 eV 标注），ε₁ 轴只留 −10/0/10/20 四个值，ε₂ 轴只标 0 与最大值；
- 当前光子能量画成"三点一线"：地面上的 ε₂ 影子、后墙上的 ε₁ 影子、以及悬空的三维点；
- 吸收系数 α 从主图里拆出去，变成右侧一个**独立面板**（自带 ω 轴与峰值标注），不再跟主曲线抢位置。

另外把 Kramers–Kronig 的输出又做了一次 5 点平滑、ε₂ 的平滑核加宽到 9 点：
KK 在吸收边附近本来就会过冲，不处理的话三维曲线会出现垂直跳变（看起来像渲染坏了，其实是数据太尖）。

**谱精度两档（可调 k 网格）。** JDOS 的 k 网格做成了参数：`快速 9³` 与 `精确 15³`。
实测（同一台机器、含 EPM 求解）：9³ ≈ 0.34 s、15³ ≈ 0.62 s（浏览器里含页面开销约 1 s），
结果按 `材料 × 网格 × 温度 × 展宽` 缓存，只有换材料/换档位/改温度才重算。
重算走 busy 遮罩（`expensive()` 钩子告诉外壳这次很贵），不会让画面假死。

需要说清楚的是：**网格加细只能让 JDOS 采样更收敛**（ε₂ 峰值从 49.7 收到 46.1，
ε₁ 的单步最大跳变从 2.55 降到 2.24），它压不平在 vHs 处那道陡降——
那道陡降是 Kramers–Kronig 关系对尖峰的**物理响应**，真正的旋钮是展宽 Γ（寿命展宽）。
所以面板上把两者并列：想更平滑，先把 Γ 拉大；想更收敛，再换 15³。

### 4.3 Xel 集成的四个要点

1. **四个 `<meta>`**：`xel-theme`（`fluent-dark`）、`xel-icons`、`xel-accent-color`，
   本地化文件可选（纯中文界面不需要）。
2. **Electron 下不要用 `file://`**：Xel 的图标/主题是运行时 `fetch` 加载的，
   `file://` 会被拒。主进程注册 `app://` 协议映射到项目根目录，页面用同源相对路径即可。
3. **CSP** 保留 `style-src 'unsafe-inline'`（Xel 会写内联样式），`script-src 'self'` 不需要 `unsafe-eval`。
4. **无边框窗口**：`frame: false` + `-webkit-app-region: drag`（标题栏）
   / `no-drag`（按钮），`buttonclick` 事件转发到 `ipcRenderer`。

### 4.4 为什么自研 WebGL 引擎

- **零依赖**：不引 three.js（600 KB + 版本漂移），全部 ~450 行，行为完全可控。
- **三种图元批处理**：折线/点/三角面各一个 VBO + VAO，每帧重建、一次 draw call 一类。
- **文字用 HTML 覆盖层**：投影后写 `left/top`，比字体图集清晰得多，还能被选择/主题化。
- **拾取不用颜色缓冲**：场景稀疏，直接在屏幕空间比较投影距离（容差随深度缩放），
  比离屏渲染一遍便宜且稳定。
- ⚠️ **踩过的坑**：不绑定独立 VAO 时，上一个程序启用过的属性数组会越界读取，
  使 `drawArrays` 变成 `INVALID_OPERATION`，**整幅画面消失但没有任何报错**。
  现在每个图元都有自己的 VAO。

## 4.6 液态玻璃 + 立体层（glass.css）

界面不再是一块平面：底下是一层**色雾**，上面浮着几片**玻璃**。

| 层 | 做法 |
|---|---|
| **色雾底** | `html` 上五层径向渐变（橙 / 青 / 蓝紫 + 左右两团侧光），固定不随滚动 —— 玻璃后面必须有东西可透，否则模糊等于没有 |
| **玻璃片** | `background: rgba(255,255,255,.46~.76)` + `backdrop-filter: blur(32px) saturate(2)` + 内侧四边高光（`inset 0 1px 0 white`）+ 160px 颗粒噪声（`mix-blend-mode: overlay`，opacity .05） |
| **投影分层** | 三层阴影：贴地 2px、近场 16px、远场 44px；标题栏用更长的 `--float-2`，视觉上压在最上层 |
| **层级** | 标题栏 z30 > 传送带 z12 > 状态栏 z10 > 检查器 z9 > 左栏 z6 > 视口（用 inset 阴影做成"凹进去"的窗口） |
| **控件质感** | 分段控件/滑轨改成"凹槽"（`inset` 阴影），滑块拇指加一圈彩色光晕，导航项选中时是一块微微凸起的玻璃 |
| **浮层** | 菜单/对话框/抽屉同样玻璃化，`::backdrop` 加深 + 模糊 |
| **暗色** | 同一套配方，玻璃换成"烟熏玻璃"（深色 0.44~0.66 + 白色 8% 顶边），色雾换成暗场霞光 |

设计上刻意保留了两条约束：

- **信息密集的面板更"实"**：左栏与检查器用 `--glass-panel`（0.76），标题栏/传送带才用 0.46 —— 玻璃感不能以牺牲文字对比度为代价。
- **不做透视倾斜**：试过 1.6° 的 `rotateY`，在 4K/缩放下文字会轻微发虚，收益不抵风险；立体感交给投影分层与圆角。

### 4.6.1 缓慢流动的高光（specular sweep）

在每片玻璃上再叠一条柔和的斜向光带，**12 s 一个循环**，各面板用负延迟错开相位
（标题栏 −1.5 s、左栏 −3.4 s、检查器 −6.2 s、传送带 −8.6 s、状态栏 −10.4 s），
看起来像液体在不同厚度的玻璃里依次传导，而不是整屏一起闪。

三个实现上的取舍：

| 取舍 | 原因 |
|---|---|
| 只动 `transform` / `opacity` | 光带是独立的 `::after` 层，走合成器；不会触发重排，也不会重绘整块面板 |
| 不用 `filter: blur()` | 模糊要在动画每帧重算，代价比"多写几个渐变节点"高得多——柔边直接由渐变的 6 个 stop 做出来 |
| `mix-blend-mode: soft-light` | 用 `screen` 会把深色文字一起提亮（高光扫过时文字会"消失"）。实测：`screen` 时文字最暗像素从 26 升到 72，`soft-light` 时保持 26–30 |
| `prefers-reduced-motion: reduce` | 系统开了"减少动态效果"就整条光带 `animation: none; opacity: 0` |

## 5 物理保真度：哪些是真算，哪些是模型

| 层 | 真算 | 模型/近似 | 已知边界 |
|---|---|---|---|
| L1 | 倒格矢、BZ 半空间裁剪、最近邻 | 结构库只有 5 种 | 无表面/缺陷/应变 |
| L2 | 平面波 EPM 矩阵 + Jacobi 对角化（46 带） | 形状因子按实验带隙标定；对称赝势（无离子性）；无 SOC/磁性 | Si 1.135（实验 1.12）、Ge 0.653（0.66）、C 5.485（5.47）——**带隙对得上，但这是标定的结果** |
| L3 | 自旋波解析式、Brillouin 自洽解、磁滞唯象模型 | 经典矩、最近邻、无量子涨落修正 | Tc 固定 320 K；斯格明子为解析 ansatz |
| L4 | JDOS 求和（含 p 矩阵元）、Kramers–Kronig、Drude | 26 个平面波、6³ k 网格、ε∞ 归一化 | 峰位近似；无激子束缚能的第一性原理；无局域场修正 |
| L5 | RSA 构型、g(r) 直方图、S(q) 傅里叶变换 | S(q,ω) 用扩散型 Lorentzian | 有限尺寸（150 原子）→ 大 r 处 g(r) 噪声 |
| L6 | RK4 积分 Bloch 方程 | T₁/T₂ 为输入参数 | 未含辐射阻尼/量子修正 |
| L7 | 复数态矢、真 Q-sphere 映射、concurrence | 无噪声通道 | 仅纯态（未做混合态/通道） |
| L8 | 复矩阵乘法模拟门序列 | 无噪声、无测量坍缩（M 仅是标记） | 3 qubit 以内 |

**结论**：这是一个"物理正确、精度有限"的交互原型——它的价值在于**结构与联动**，
而不是替代任何 DFT 或量子模拟器。真正的计算内核可以从 L2（换成本文上一篇论文的 EpNet）
与 L4（换成 GW/BSE）逐步接入，界面契约不变。

## 6 路线图

**阶段 1（当前）**：九层可交互原型，物理内核为玩具级但自洽，Xel 外壳 + 自研 WebGL。

**阶段 2（可信度）**
- L2 接入真实能带后端（EpNet / pymatgen / QE 导出），把形状因子标定替换为模型推理；
- L4 用真实 ε(ω) 数据或 GW-BSE 结果替换 JDOS 玩具；
- 加"数据来源"标记（每个读数点注明是模型还是实验）。

**阶段 3（联动）**
- 真正的跨层参数总线：一个 (材料, T, ω) 元组同时驱动 L2/L4/L5；
- 把"能带 → 自旋"的 J 从超交换公式算出来，而不是手调；
- 电路层加噪声通道（Lindblad），与 L6 的 T₁/T₂ 共用参数。

**阶段 4（协作与出版）**
- 把当前视图（相机 + 参数 + 选中对象）序列化为可分享的 URL/文件；
- 场景脚本化：允许用户写一段"从能带选 k → 算跃迁 → 画在光谱上"的宏；
- 导出为矢量图（SVG）用于论文插图。

### 4.6 数据导出（CSV / JSON）

三个入口，同一条实现（`src/export.js`）：

| 入口 | 用法 |
|---|---|
| 菜单 | 文件 → 导出本层数据 CSV |
| 快捷键 | `Ctrl+E` |
| MCP | `atlas_export {format: "csv"\|"json", save: true}` |

导出的不是屏幕字符串，而是**算出来的数组**：

| 图层 | 数据集 |
|---|---|
| L1 晶体 | 晶格矢量、基元分数坐标、BZ 面/顶点数 |
| L2 能带 | `Ek`（118×14：k_index/kdist + E1..E12，VBM 对齐 0）、`path`（节点标签） |
| L3 自旋 | `magnon`（qx/qy/|q|/ω，meV）、`levels`（m/E/dE） |
| L4 光谱 | `epsilon`（ħω, ε₁, ε₂, α） |
| L5 液态 | `gr`（r, g(r)）、`Sk`（q, S(q)） |
| L6 Bloch | `bloch`（t, Mx, My, Mz, |M|） |
| L9 器件 | `model`（19 个标量）、`tempScan`、`fluxScan` |
| 其余 | `readout`（读数键值） |

CSV 头部是元数据，**能看出来哪个数是标定的**：

```
# Quantum Atlas export
# kind: bands
# material: Si
# generatedAt: 2026-11-19T11:19:55.000Z
# app: Quantum Atlas 0.9.0
# param.material: Si
# dataset: Ek — 能带 E(k)，VBM 对齐到 0；nG=46、mesh=6；gap=1.1347 eV（间接）
k_index,kdist,E1_eV,...
```

`GET /export?format=csv&save=1` 会把文件写到 `docs/exports/`，所以 MCP 客户端也能拿到落盘副本。
