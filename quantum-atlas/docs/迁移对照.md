# Fermi (PyQt) → Quantum Atlas (Electron) 迁移对照

原程序 `I:\Fermi\src\*.py`（PyQt6 + matplotlib + numpy，xraylib 可选）是一个**半导体探测器模拟器**。
新框架 `I:\Fermi\quantum-atlas`（Xel + 自研 WebGL2）把它整体收进 **L9「器件」层**，
其余八层保持原有物理主题不变。

## 一、模块级对照

## 三、原缺口的三处补齐（已做）

1. **衰减系数：两套实现可切换。**
   浏览器端没有 xraylib 的 WASM 构建（官方只有 C 库 + 各语言 bindings），
   所以"精确档"直接用了 xraylib 的数据来源本身——**NIST XCOM 质量衰减系数表**：
   `scripts/fetch-nist.py` 抓取 14 种元素（C/Si/Zn/Ga/Ge/As/Br/Cd/Te/I/Cs/Hg/Tl/Pb）
   4–600 keV 的 μ/ρ，存成 `src/phys/atten-nist.js`（5 KB）。
   `attenuation(mat, E, source)` 的 `source` 可选 `"nist"`（默认，log–log 插值 + 质量分数加权）
   或 `"mock"`（原程序的解析近似）。面板上就是「衰减数据：精确 NIST / 快速近似」。
   实测差异（CZT，60 keV，1 mm）：NIST μ = 37.2 cm⁻¹ → 吸收效率 97.6%；
   原近似 μ = 607 cm⁻¹ → 100%（偏高约 16 倍）。**K 边位置与跳变现在是真的。**

2. **T-Scan 页补上了。** 新增「温度扫描」视图：上panel 是 FWHM vs T（Fano + 电子学噪声），
   下面板是暗电流 vs T（对数轴），一条竖线标出当前温度，旁边给出 n_i(300 K)。

3. **材料库支持自定义材料。** 对话框底部加了一个表单（名称/Eg/µe/µh/τe/τh/W/密度/成分），
   成分支持 `Cd0.45Zn0.05Te0.5` 或 `Cd:0.45,Zn:0.05,Te:0.5` 两种写法，自动归一化；
   保存进 `localStorage`（键 `qa:detectors`），启动时载入并合并进材料列表，
   自定义行带「删除」。这等价于原 `RepositoryDialog` 的"手工成分"路径。
   （仍然没做的：从 URL 抓取材料目录、导入外部 JSON。）

## 四、仍未迁移

- **xraylib 原生绑定**：只有当项目愿意引入 WASM 构建时才可能；当前用 NIST 表，
  精度等价（NIST 就是其数据源），但少了 xraylib 的边能量/荧光产额等附属数据库。
- **材料目录抓取 / 批量导入**。
- **中英双语切换**：原文 270 条键值，新界面固定中文。
- **多材料并行对比列表（最多 4 个）**：新界面是"一个当前材料 + 全材料评分柱"。


## 四、迁移时做的三处"向上兼容"

- **能带页不再重复**：原程序的 Band tab 只是 Ev/Ec/Ef 三条线示意；新框架 L2 已有真实 EPM 色散，
  器件层直接引用，避免两套能带说法。
- **图表统一进 3D**：8 张 matplotlib 图改成正对相机的 3D 图表（同一套坐标系与标签规则），
  这样"视图切换"看起来是同一个工作台的不同切面，而不是嵌入的图片。
- **参数语义对齐**：厚度/偏压/温度/能量四个滑块与原程序的 QSlider 范围、步长、
  默认值（1 mm / 300 V / 300 K / 60 keV）一致，读数保留原单位。
