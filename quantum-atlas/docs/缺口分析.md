# 缺口分析：距离"真的能算、能出结果"还有多远

> 排查方式：读实现（`src/phys/*.js`）+ 跑收敛实验（`scripts/probe-convergence.mjs`）+ 对照案例库里的说法。
> 所有数字都是本机实测，可复现。

## 一句话结论

**数值内核是真的（平面波 EPM + Jacobi、带间跃迁 + Kramers–Kronig、RSA + g(r)、RK4、精确态矢、Hecht/泊松/蒙特卡洛 + NIST 表），但参数是被标定到实验值的，且只有极少数几个截断点被验证过。**
它现在是一个**可信的"物理直觉 + 量级"工具**，还不是一个能出论文图的**定量**工具。差别不在"有没有公式"，而在**收敛性、误差棒、可导出**这三件事。

## 一、实测证据：结果对截断有多敏感

### 平面波截断（k 路径固定，mesh=8）

| 材料 | nG=19 | 27 | **46（默认）** | 65 | 89 | 极差 |
|---|---|---|---|---|---|---|
| Si 带隙 eV | 1.105 | 1.219 | **1.135** | 0.978 | 1.019 | 0.24 |
| Ge 带隙 eV | 0.640 | 0.713 | **0.653** | 0.519 | 0.548 | 0.19 |
| C 带隙 eV | 7.999 | 7.663 | **5.485** | 4.776 | 5.078 | **3.22** |

- 默认的 46 个平面波**恰好**是让 Si/Ge/C 都贴近实验的那个点——形状因子就是在这个截断下标的定。
- 加大截断后结果**不收敛到实验值**，反而偏离（Si 0.98、C 4.78）。说明"1.135 eV"是**标定结果**，不是**收敛结果**。
- 金刚石最严重：±3 eV 的漂移。C 的"5.485 vs 5.47"是同一个标定点的巧合，不能当作独立验证。
- `nG=11` 时 Si/Ge/C 的 gap 全部变成 0.0000——基组太小导致价带与导带在 Γ 处简并。**界面上没有任何防护**，用户把截断调低就会看到"金属"。

### k 网格（nG=46）

带隙 4 → 12 完全不变（1.1347），因为 gap 取的是高对称路径，不依赖 BZ 积分。这是**对的**，但也意味着"带隙收敛"这件事本身没被网格检验过。

### 介电函数（Si，nG=26）

| mesh | ε₂ 峰值 | 峰位 eV | ε₁(0) |
|---|---|---|---|
| 3 | 80.7 | 3.66 | 11.70 |
| 4 | 58.3 | 3.66 | 11.70 |
| 6 | 53.6 | 3.68 | 11.70 |
| 8 | 49.8 | 3.76 | 11.70 |
| 10 | 49.5 | 3.74 | 11.70 |

- ε₂ 峰值从 80.7 掉到 49.5，**到 mesh=10 仍在漂**（约 0.7%/步）。峰位移动 0.1 eV。
- ε₁(0) 永远是 11.70：因为 `spectra.js:82-90` 把整条谱**缩放**到查表得到的 ε∞。所以 ε∞ 是**输入**，不是预测；ε₂ 的绝对高度也跟着这把尺子走。
- 案例库 L4 把"ε∞ ≈ 11.7"写在数字胶囊里，读起来像算出来的——**这是要改的表述**。

## 二、逐模块判定

| 层 | 实现 | 判定 | 说明 |
|---|---|---|---|
| L1 晶体 | 晶格/惯用胞/原胞/BZ 几何 | ✅ 真几何 | 与晶体学定义一致；BZ 由 Voronoi 构造 |
| L2 能带 | 平面波 EPM + Jacobi 对角化 | ⚠️ 真算法、标定参数 | 截断未收敛（见上表）；无 SOC、无自旋极化、无应变 |
| L3 自旋 | 解析自旋波色散（Γ–X–M–Γ）+ 唯象 Lorentzian 展宽 | ⚠️ 半解析 | 方格子公式，不是对角化动力学矩阵；不能处理多子晶格/各向异性交换 |
| L4 光谱 | 带间跃迁求和 + KK 变换 + 标定 ε∞ | ⚠️ 真求和、标定幅度 | 激子只是经验振子；ε₂ 绝对值取决于标定与网格 |
| L5 液态 | RSA 构型 + g(r) + S(k) | ✅ 真统计 | `dynamicFactor` 是扩散唯象，不是动力学模拟 |
| L6 Bloch | Bloch 方程 RK4（唯象 T₁/T₂） | ✅ 真积分 | 不是 Lindblad/主方程；`blochWave` 面板是**示意**（代码里明写"示意"） |
| L7 量子态 | 精确态矢 + Q-sphere/扇区 | ✅ 真 | 指数墙：>~14 比特内存爆 |
| L8 电路 | 复数态矢逐门演化 | ✅ 真 | **无噪声模型**，所以算不出保真度/退相干 |
| L9 器件 | Hecht + 1D 泊松 + 蒙特卡洛 + NIST 表 | ⚠️ 真但降维 | 1D，无像素间电荷共享、无读出电子学、无权重势 |

## 三、缺口清单（按"卡住什么"排序）

### P0 — 不改就谈不上"能给结果"

1. ~~**没有数据导出。**~~ ✅ **已补**（`src/export.js` + 文件菜单 / `Ctrl+E` / `atlas_export`）。
   → 每个图层加"导出 CSV/JSON"，带元数据（材料、nG、mesh、γ、时间戳、git hash）。**这是"能出结果"的最短路径。**
2. **没有收敛性报告。** 现在只有 10 条"结果有限/带数够"的断言，没有一条比较文献值或检查收敛。
   → 把 `probe-convergence.mjs` 变成 `pnpm test:conv`，输出随截断的漂移表；UI 在低截断时给黄条警告。
3. ~~**案例里的「结果」与「标定量」混在一起。**~~ ✅ **已补**：读数行加了 ●计算 / ◆标定 / ■输入 三色点（`src/provenance.js`），L2/L4/L9 顶部有边界提示条；案例卡的数字也标注了来源。
   → 卡片上加"标定 / 计算"标签，或在数字胶囊里标注来源。

### P1 — 决定"能算哪类问题"

4. ~~**无自旋轨道耦合、无自旋极化**~~ ⚠️ **部分完成**：Zeeman 分裂（gμ_B B）与自旋极化率是严格算的，交换劈裂作为输入叠上去；SOC 只给了文献 Δ_SO 的量级（价带顶三重态分裂），**不是**从头算的 spinor 能带。仍缺：真 spinor EPM（基组翻倍 + 重新标定）、Rashba/Dresselhaus 的 k 依赖分裂、拓扑不变量计算。
5. ~~**无温度依赖计算**~~ ⚠️ **部分完成**：`src/phys/thermal.js` 用热膨胀 + 德拜-瓦尔阻尼做了刚性离子温漂（真算），并把它与 Varshni 并排显示——实测只解释 20–36% 的红移，剩余部分正是缺的电声自能（Fan 项）。迁移率、载流子寿命仍只能给经验值。
6. ~~**激子只有经验振子**~~ ⚠️ **部分完成**：`src/phys/exciton.js` 从 EPM 曲率取 m*_e/m*_h，解 Wannier–Mott 氢原子型方程给出 E_b 与 a_B（Si 14.7 meV，与文献一致）。仍缺：各向异性/多带、电子-空穴交换、BSE 级别的吸收边形状——所以谱线本身还是经验振子，只有束缚能是真算的。
7. ~~**自旋波没有对角化动力学矩阵**~~ ✅ **已补**：`src/phys/magnon.js` 用 `(A−B)(A+B)` 的本征值给出频率，支持 J₂ 与双子晶格反铁磁，并与旧解析式逐点一致。仍缺：非共线/螺旋磁结构、有限温度（Bose 占据只做展宽）、以及多轨道磁体。
8. ~~**量子部分无噪声**~~ ✅ **已补**：`src/phys/quantum-noise.js` 用密度矩阵 + 振幅/相位阻尼，输出保真度、纯度、concurrence，并与 L6 的 T₁/T₂ 共用参数。仍缺：门本身的相干误差（过旋转/串扰）、读出误差、以及 n>4 的近似（密度矩阵指数增长）。
9. **器件是 1D**：无像素间电荷共享、无读出电子学噪声、无权重势 → 不能回答"能谱会不会糊"这类真问题。

### P2 — 数值与工程债

10. ~~**稠密 Jacobi O(n³)**：nG=89 已 4.1 s~~ → **实测否决**：那 4.1 s 是 **118 个 k 点**的总耗时，
    单次对角化在 n=89 只有 **8 ms**（`eigSym` 本来就只做 8 轮 sweep，是低常数的 O(n³)）。
    写了个 Lanczos（完全重正交）做对照：n=400 时快 5–9×，但 n≤89 反而更慢。
    结论：**当前规模 Jacobi 已是最优，不改**。将来上超胞 / nG>300 才需要换，且那次替换必须先通过
    「与 Jacobi 逐点一致」的验收——试写时出现过伪本征值 −2.77，就是因为跳过了这一步。
11. ~~**k 网格无对称性约化**~~ ✅ **已补**：`src/phys/kgrid.js` 用 Wigner–Seitz 判定 + 立方群 48 操作折叠，mesh=8 压缩 25.6×，且与全网格**严格一致**；省下的预算换来 mesh=24（76 ms，峰高收敛到 2.3%）。仍缺：六方/四方晶系的点群（现在只做立方）、以及非线性网格（如四面体法）。
12. ~~**无误差棒/无收敛判据输出**~~ ✅ **已补**：L4 画出 ε₂ 的收敛带（mesh 与 mesh/2 的差），读数给出 `收敛带 @峰 ±X%`；`test-convergence` 与 `test-physics` 都断言逐级加密的差递减（15→24 为 1.1%，8→15 为 18.5%）。仍缺：其他图层（能带/g(r)/S(q,ω)）还没有误差带。
13. **缓存 key 不含全部参数**（如温度），存在脏读风险。
14. **无项目保存/加载**：自定义材料在 localStorage，其余状态刷新即失。

### P3 — 产品化

15. 无"公式与出处"面板（每个模型该引哪篇，现在只在文档里）。
16. 无批量扫描（参数网格 → 一张图）；MCP 只能单点调用。
17. 单位/量纲没有集中校验（各模块各写一套 Å、eV、Ry 换算）。

## 四、"算对了"的验收门槛（建议写进 CI）

| 量 | 判据 | 现状 |
|---|---|---|
| Si/Ge/C 带隙 | 对 nG=89 与实验同时 <5%，且 46→89 漂移 <2% | ❌ 漂移 12~40% |
| 直接带隙 ε₂ 峰位 | 与文献差 <0.1 eV，且 mesh×2 后峰位变化 <0.02 eV | ⚠️ 峰位差 0.1 eV，mesh 仍在漂 |
| ε₂ 峰值 | mesh×2 后变化 <3% | ❌ 8→10 仍 0.7%/步，3→10 差 60% |
| g(r) 第一峰 | 与 X 射线/中子数据差 <2% | ⚠️ 未做对照（只验证了形状） |
| 自旋波带宽 | 与解析式/文献一致 | ✅（解析式本身就是基准） |
| 量子电路 | 与已知 Bell 态振幅一致 | ✅ |
| 器件 CCE | 与 Hecht 解析解一致 | ✅（同一实现，自洽而非独立验证） |

## 五、建议的最小闭环（两周量级）

1. **导出**：`E(k)` / `ε(ω)` / `g(r)` / `S(q,ω)` → CSV（含元数据头），再加一个"导出当前图层全部数据"的按钮。
2. **收敛**：把 `test:conv` 接进 `pnpm test`，CI 里对 Si/Ge/C 断言"46→89 漂移 < X%"；不达标就红。
3. **标注**：案例卡与读数里区分「计算值 / 标定值 / 输入常数」，并在低截断时显示警告条。

做完这三件，它就能诚实地回答"我算的数和文献差多少、为什么"——这才是"能仿真计算问题并给出结果"的定义。
