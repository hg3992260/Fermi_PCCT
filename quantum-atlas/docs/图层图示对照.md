# 图层图示对照：从论文配图到界面

左栏每一层的图标与三维呈现形式，都不是随手画的，而是照着该领域论文里**最稳定的那一种配图惯例**做的。
调研方式：arXiv API 按主题检索 → 抓 ar5iv 全文的 `<figcaption>` → 挑出重复出现、跨论文一致的视觉语法
（原始抓取结果见 `docs/fig-survey.json` / `fig-survey2.json`，下载的样图在 `docs/figs/`）。

## 从配图里学到的三条"呈现规则"

1. **一层只讲一件事**：论文的 panel 从不在同一张图里同时画能带和介电函数。界面因此给每层一个主三维载体，其余信息进读数区。
2. **2D panel 也能进 3D，但要"折成投影"**：L4 的 ε₁/ε₂ 是两张并排图，折成"地面 + 后墙"后仍然保持"两张图"的可读性。
3. **方向标要常驻**：L1/L3 的论文图几乎都在角落放 a,b,c 方向标；界面用右下角随相机旋转的迷你坐标轴实现同一件事。

## 图标实现

`src/glyphs.js`：10 个 16×16 视觉框的手写 SVG（`viewBox 0 0 16 16`，描边 1.5，颜色 `currentColor`），
在启动时替换掉左栏原有的 Xel 通用图标（房子/方块/条形/圆点/地球/时钟/滑杆/代码/芯片），
选中态跟随强调色（`.glyph` 用 `currentColor`，由 `x-navitem[toggled]` 染色）。

### 据此做的一处改动：L3 的 S(q, ħω) 强度图

原来 L3 右侧只有一条磁振子色散曲线，而论文配图是**二维强度图**。现在改成：

- 每个 q 上把色散按 Lorentzian 展宽（半宽取带宽的 3.5%，模拟仪器分辨率），乘玻色占据因子；
- 先算全网格峰值再归一（`I/Imax` 的 0.42 次幂），避免 1/E 发散把整块烧成红色；
- 色带 ice→violet→amber→pink 表示强度，色散脊线叠在最上层，坐标仍标 Γ–X–M–Γ。

这样一层里同时有"强度分布（实验视角）"和"色散关系（理论视角）"，与中子散射论文的读图方式一致。

### 已补上的两处（本轮）

**L1 双胞套嵌**（`src/scenes/crystal.js`）：惯用胞（灰边 + 玻璃面）里再套一个**原胞**（红边 + 5% 红面），
与惯用胞共角点；a₁a₂a₃ 标在原胞的三条棱上，图例加一行"原胞（红）"。
fcc/金刚石用 a/2(0,1,1) 那组基矢，bcc（Na）用 a/2(−1,1,1) 那组，二维材料（石墨烯）不画原胞。
读数里的"原胞体积 40.05 Å³"正好是惯用胞 160.2 Å³ 的 1/4，与图上 4:1 的比例自洽。

**L7 半球扇区**（`src/scenes/qubit.js`）：作为 Q-sphere 之外的第二表示法（`表示法` 分段控件）：

- 扇区**张角 = 2π·pᵢ**（面积即概率），按基态顺序绕圈排布；
- 扇区填充色 = 相位色（ice→amber），**相位针**再按 arg(amp) 在本扇区内偏转；
- 相邻扇区用交替明度 + 实线分界 + 彩色外弧区分，即使两个基态同相位也能看出分区；
- 整块盘做**朝向相机的 billboard**，所以在 3D 里始终正对视线，不会因为转视角变成一条线。

两个表示法解决的是同一个问题的两端：Q-sphere 擅长看"多比特的层级与纠缠结构"，
扇区擅长看"2–3 个基态各自的概率与相位"——与那篇论文的用法一致。
