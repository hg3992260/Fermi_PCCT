本层物理

一个母方程，八个尺度站点

整个工作台只依赖三条不变式：谱定理、涨落–耗散（Kubo）、粗粒化（有效哈密顿量）。每一层都是同一结构在不同尺度上的重正化。

∂ₜρ = −i[H, ρ] + Σₖ γₖ ( LₖρLₖ† − ½{Lₖ†Lₖ, ρ} )
层自由度生成元三维载体
L1 晶格核 + 电子H = T + V + e²/r实空间晶胞 / 倒空间 BZ
L2 能带Bloch 态 nkH(k) = e−ikrH eikr(k∥, k⊥, E) 曲面
L3 自旋局域矩 SiΣ JijSi·Sj + DMI箭头场 + 磁振子谱
L4 响应极化 P(q,ω)χ = Kubo(ω, ε₁, ε₂) 曲线
L5 液态无序自旋旋量费米液体 / 无序 Heisenbergg(r) + S(q,ω) 曲面
L6 Bloch二能级 / M(t)Bloch 方程Bloch 球 + 轨迹
L7–L8 量子n qubit分段 H(t)Q-sphere + 演化塔

三种三维语法

  • 多面体 = 对称性的基本域：布里渊区是倒格子的 Wigner–Seitz 胞。
  • 曲面 = 谱：E(k)、ε(ω)、S(q,ω) 都是某个自伴算符的谱数据。
  • 球 = 状态空间：Bloch 球 = CP¹，Q-sphere = 2ⁿ 维希尔伯特空间的半径–相位嵌入。
