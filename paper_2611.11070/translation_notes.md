## 2 术语决定

| 原文 | 采用译法 | 理由 / 备选 |
|---|---|---|
| empirical pseudopotential method (EPM) | 经验赝势方法 | 学科通用译法；不用"经验伪势" |
| specie potential | 种类势／元素势 | 原文 *specie* 是作者自造词（指"元素种类"），首次出现时两译并列，避免与"物种"混淆 |
| nonlocal projector | 非局域投影子 | 与"非局域赝势"区分：本文指 separable 形式中的 β 投影子 |
| ultrasoft pseudopotential | 超软赝势 | 与 norm-conserving（模守恒）对举 |
| norm / norm deficit | 模／模亏损 | 量子化学惯用"模"（norm），不用"范数" |
| overlap operator / matrix | 重叠算符／重叠矩阵 | 保留 *S* 符号 |
| equivariant neural network | 等变神经网络 | 与 invariant（不变量）、rank-2 tensor（秩 2 张量）并列 |
| hypernetwork | 超网络 | 指"生成另一网络参数的 MLP" |
| readout | 读出（头） | 介于"读出层"与"输出头"之间 |
| window MAE | 窗口平均绝对误差 | 指 ±2 eV 能量窗内的 MAE |
| chemical system | 化学体系 | 定义：共享同一组元素的所有结构（作者的划分单位） |
| sealed chemical systems | 封存化学体系 | 训练前封存、只打分一次；相当于单次盲测 |
| metal/insulator classification | 金属/绝缘体分类 | 保留"判对率"说法 |
| screening mode | 筛选模式 | 路径抽稀 + 5 meV 容差的快速推理 |
| convex hull | 凸包 | 热力学稳定性参照，单位 eV/atom |

## 3 公式与符号

- 式 (1)–(6)、式 (S1)–(S9) 均由 PDF 文本层提取后**重新排版为 LaTeX**，编号与原文一致。提取时上下标、求和号、希腊字母存在错位（例如 `𝑣specie`、`𝐷𝑍𝑙𝑟` 被拆成多行），已按上下文重建；未改变任何数值或符号含义。
- 原文用粗斜体表示矢量（**q**、**k**、**G**、**p**），标量用斜体；本读者沿用这一区分。
- 引用上标（如 `³⁻⁹`、`⁴³`）按原样保留，与文末编号一致。
- 式 (S7) 中的 `T_2` 指 *l* = 2 的径向动能算符 T_l；原文 p.26 给出其定义，本读者在 S115 的中文里补出。

## 4 不确定与已知偏差

1. **式 (3) 的 D_ij 含义**：原文写作 D_ij = ⟨φ_i|ε_j − T − V_loc|φ_j⟩ + ε_jQ_ij，其中 ε_j 在括号内、外各出现一次。这与 SI 式 (S8) 的 D_ij = B_ij + ε_jQ_ij 一致（B_ij = ⟨φ_i|χ_j⟩，χ_j = (ε_j − T_2 − V_loc)φ_j），因此转录无误；但读者若自行推导应注意 T 在此为算符、ε_j 为标量。
2. **图注中的面板字母**：图注原文的 **a**、**b** 等粗体已保留；中文图注同样标注面板，便于对照看图。
3. **图 1e 的灰色元素**：He、Ne、Ar、Kr、Xe、La、Po、At、Rn 在原文中为灰色（不在覆盖范围）；本读者在阅读提示中明确指出"63 种元素"是训练集并集，而非全周期表——这是对原文口径的澄清，不是原文的表述。
4. **表 S2 的 29 行数值**：逐格转录自 p.27；"–"表示该元素不学习轨道伸缩（λ = 1），不是缺失值。
5. **表 S3**：原文只有表题（p.29），无表注；本读者按单元格内容重建为 Markdown 表，未增删条目。
6. **页码标注**：`**Source:** p.X SYYY` 中的页码是**该段落在原 PDF 中的起始页**；跨页段落（如 S021、S023）标为 `p.7–8`、`p.8–9`。
7. **参考文献未翻译**：p.14–20 共 79 条，本读者不含其译文；正文中的编号可直接回查原 PDF。
8. **图裁剪边界**：以图形对象（矢量绘图 + 位图）的包围盒为准，外扩 6–12 pt，并以图注首行为下界；图注文字本身未纳入图片，而是单独以文本形式给出。个别图的坐标轴标签贴近裁剪边缘（如 fig2 的纵轴标签），已在裁剪时额外外扩 12 pt。
